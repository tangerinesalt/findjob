# Fingjob

轻量岗位研究插件，包含四个技能入口：

| 入口 | 用途 |
|---|---|
| `job-profile` | 根据需求、简历或已有画像生成可编辑的 Markdown 求职画像 |
| `job-search` | 搜索并筛选近期岗位，输出附来源的简表和详情 |
| `job-enrich` | 补充既有清单的职责、福利、工时及企业信息 |
| `job-refresh` | 重新核实既有岗位的日期、状态和筛选条件 |

## 验证与已知问题

在工程根目录执行现有本地测试：

```text
python -B -X utf8 -m unittest discover -s tests -v
```

2026-09-28 基线复制后，现有 38 项测试通过。此前独立扩展检查仍发现以下问题，现有测试未覆盖其全部影响：

1. 搜索报告简表表头与分隔行列数不一致，影响 Markdown 表格渲染。
2. 自动选择最新清单时，部分分析文档可能被误选。
3. 跨目录另存报告可能使相对链接失效。
4. 长文件名追加补充或复核后缀可能导致保存失败。
5. 重复岗位日期和详情字段数量相同时，输入顺序会影响选留结果；互补详情尚未自动合并。

后续改造重点包括查询覆盖与信息增量、证据合并、输出稳定性、token 消耗及共享模块边界。以上改进均未在此基线实现。

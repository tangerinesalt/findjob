## 宿主验收范围与限制

- 发布以Windows为主。Linux/macOS仅声明上述脚本CI结果，没有执行这两个系统的完整宿主会话验收。
- Codex CLI无交互会话在执行任务前被账号拒绝：配置的模型不可用，按原生model/list返回的默认模型重试仍失败。因此没有把CLI端到端测试标为通过；当前Codex会话完成了安装目录技能与真实在线工具的衔接验证，全局模型设置未改动。
- Claude Code在用户已有提供方配置下运行。首段会话完成画像与搜索，实际2次query、6次页面访问，形成5条主表岗位；15分钟测试时限在补详prepare后中断。降低测试进程思考强度并提供明确续接命令后完成后两入口，原全局配置未改动。这是分段、带引导的宿主验证，不代表无人引导整轮可靠性、Anthropic官方模型或所有提供方均已验证。
- 真实续接中代理曾提交未知字段及含说明文字的sources，脚本拒绝后修正成功，原报告未变。最终版补充了可直接使用的状态变更示例和更具体的错误提示，未放宽字段或来源校验。用户查询上限曾仅被预留而未持久化，已补充技能要求，并单独验证现有覆盖接口能保存上限。
- Codex最小联网测试发现搜索摘要与打开页面的缓存日期不同，未将缓存相对时间当作今日证据；另一个详情返回工具错误，未推断岗位关闭。补详/复核均为0新增查询及0访问，明确不声称在线有效性复核完成。
- 未测试各求职平台来源覆盖率、招聘账号登录或缓存新鲜度保证，也未实际投递。两宿主的搜索结果数量不能作效果对比：角色、来源、预算及网络工具均不同。

上述结果支持面向Windows用户发布0.3.0，使用前仍需具备可用宿主模型与在线工具。没有据此宣称全平台覆盖、所有地区薪酬支持或所有岗位当前可投递。原开发任务材料留在工作空间，不随发布包携带。

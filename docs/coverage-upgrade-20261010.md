# 0.2.3：检索覆盖与线索续接

实现依据：[下一步改造指南](next-iteration-guide-20261009.md)。本次不使用 superpowers 工作流程。

## 行为变化

搜索开始时盘点相关历史及用户点名线索，导入身份和来源，不复制旧日期、薪资、职责或查询次数。新增可选覆盖账本，记录本轮访问关联、纳入/待核实/排除及暂缓去向；交付前检查已登记重要线索和全局停止理由。

鱼泡、LinkedIn额外池用完后，可继续使用常规预算；核心缺口通过合法公开同岗来源反查。页面版本差异须判断是否真正影响硬条件，不自动把任何时间差写成冲突。旧账本不自动迁移，日期及薪资判定函数不变。

报告覆盖区块注明原搜索日期，后续enrich/refresh保留为历史记录，更新后的主表与复核记录优先。没有新增抓取器、平台账号、联网依赖或自动投递。

测试、回放及本地真实报告共同支持本次范围内有效、未发现规则和工作流回归。不能据此宣称所有未来任务无害或不存在遗漏。来源盘点和人填证据仍需审阅，脚本无法发现未登记线索。

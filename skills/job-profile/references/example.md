# 求职画像

只修改“值”列；字段名称保持不变。此表是搜索读取的唯一配置来源。

多项用中文分号“；”分隔；空白表示未设置。布尔值填“是/否”。时间关系填“或/且”。
薪资金额以所填币种的基本单位计，0表示不设该门槛；有薪资比较周期时按该周期比较，旧月薪门槛需为0。时间窗口按自然月计算，0表示当天。
地点、招聘类型、工作方式及排除项为筛选条件；排序偏好与个人背景不自动成为硬条件。

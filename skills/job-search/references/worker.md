# 可选检索子代理任务模板

这是主代理显式读取并填充的任务文本，不是自动注册的子代理配置。

> 搜索来源范围：{sources}。检索基准日：{as_of}。本次完整画像：{profile}。
> 已分配最多 {quota} 个 query，包含补充搜索；禁止自行增加代理或突破配额。
> 用宿主可用的搜索/网页/CLI；先收基本信息和岗位直接链接，再按 evidence.md 核验。读 data.md 的统一岗位结构。
> 站点限定写 `site:域名`（半角冒号），不要写成 `site.域名`；中文交接文件用文件编辑工具或 UTF-8 脚本写入，避免 PowerShell 默认编码管道传中文代码，详见 data.md“中文读写”。
> 每完成最多 5 条就写自己的 {handoff_file}，包括实际查询日志、岗位记录、待核实原因和下一步。只写自己的文件，不修改共享 run.json 或最终报告。
> 关键证据缺失则标 unknown，缺福利/社保/讨论不要卡住。任务中断也必须尽早保留已取得结果。
> 最终回报实际 query 数、文件位置、有效/待核实条目及来源受阻情况，不要求一定找到若干条。

主代理分配不重叠的来源任务，预留各分支额度之和；汇总时检查实际 query 数、日期与来源，统一去重，按短证据抽查关键条件。分支失败时先读已落盘交接，接管剩余工作；不重复启动整段搜索。模板与规则路径需传给子代理，不能假设它继承主代理全部上下文。
